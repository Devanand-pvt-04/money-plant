# 0005: When UI and UX work starts, and its goals

Date: 2026-10-23. Agreed with Deva in the "UI and UX plan" thread.

| Decision | Choice | Why |
| --- | --- | --- |
| Timing | A design step of about a week between milestones 3 and 4, then each milestone builds on it, and the friends release (milestone 7 since decision 0006) adds a polish pass | The app has about 15 plain screens; milestones 4 and 5 roughly double that, so restyling later costs more. Deva starts daily use of the preview app now |
| Scope of the design step | Design system (tokens and core components, light and dark), bottom tabs (Home, Activity, Budgets, Money), and the four daily screens: home, review inbox, transaction list and detail, quick add | These are the screens used every day |
| Process | Clickable mockups first; Deva signs them off before any code | Cheap to change a mockup, costly to change screens |
| Goals | The UX rows in the PRD's non-functional requirements | Each goal can be checked on a real phone |
